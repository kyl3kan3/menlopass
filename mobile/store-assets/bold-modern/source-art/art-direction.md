# Background artwork generation briefs

Created with the built-in image-generation tool on September 27, 2026. These briefs record the intended composition for regeneration; they are not a transcript of the generation conversation. The final exported backgrounds are retained beside this file for exact reproduction of the campaign.

## Forest background — `forest.png`

Use case: brand background for a bold modern App Store campaign for peri, a perimenopause and menopause tracking app. Tall portrait canvas. Near-black forest green with subtle velvet texture and rich tonal depth. A single broad, sculptural acid-lime ribbon curves through the lower half, satin light on the edge. Upper 45 percent is clean dark negative space for a large headline. The composition should feel editorial, confident and premium. No text, letters, phone, tablet, user interface, logos, icons or watermark. Opaque background.

## Lime background — `lime.png`

Use case: companion brand background in the same campaign. Tall portrait canvas. Luminous lime green around #D6F27B with a subtle premium texture. A broad deep forest ribbon around #092F29 sweeps from the right around 55 percent down and curves toward the lower left. Upper 45 percent stays clean lime negative space. Restrained, confident contrast; soft dimensional lighting; no small decorative objects. No text, letters, phone, tablet, user interface, logos, icons or watermark. Opaque background.

## Final composition constraints

- Add typography as editable SVG with the native graphics compositor.
- Use only actual native screenshots for the app UI.
- Preserve original UI text and data; magnified details must be contiguous source crops.
- Export at the exact device-specific App Store dimensions.
