# Pip content batch

Three concepts, each with a two-image post, a 10.5-second mascot video, an 8-second slideshow, caption and alt text. All media are 1080 × 1920. Videos are silent so you can choose platform audio.

Open index.html to review. ready-to-post.zip contains the media and text, grouped by concept. Nothing has been published.

Recreate with node tools/mascot-studio/create-content.cjs from the repository root. The existing Masko animation and crisp mascot poses are reused; no new generation credits are needed.
