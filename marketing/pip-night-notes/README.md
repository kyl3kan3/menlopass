# The 3 a.m. brain

Two-slide post, 10.5-second mascot video, and 8-second slideshow using the crisp Pip assets. Images and videos are 1080 × 1920; videos are silent.

Use caption.txt for the post copy and alt-text.txt for accessible image descriptions. The product card is illustrated.

Edit creative.json and run node tools/mascot-studio/render.cjs --output marketing/pip-night-notes from the repository root.
